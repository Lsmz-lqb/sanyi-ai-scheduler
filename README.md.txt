# sanyi-ai-scheduler
基于三易思想的AI上层调度插件

> 定位：**不是大模型，是给AI加上一套思考章法的外壳**
> 底层需要自备大模型API / 本地模型（Ollama、GPT、Claude等）

## ✨ 核心特性
1. 三易内核：观象、简化问题、知止收敛
2. 算力分级调度：轻 / 中 / 重任务分配
3. 画面存档：本地保存推演记录，不上传云端
4. 本地习惯记录：只存脱敏标签，可清空，默认无数据回传
5. 敏感模块休眠机制：占卜、经方、健康相关模块默认关闭
   - 必须用户主动明确提问 + 确认免责，才解锁
6. 迭代规则：**有机会、遇到重大问题，才深化底层逻辑**

## ⚠️ 重要免责
本项目仅为思路调度工具。
敏感模块输出内容，仅属于这套传统体系下的参考，**不可以当作医疗诊断、生意决断、吉凶定论**。
涉及健康请找执业医师，重大事项请线下多方复核。

## 📌 和同类项目区别
市面上Agent框架（CrewAI、AutoGen、Mem0）大多是现代多智能体、记忆检索；
易学项目大多只是单纯排盘解卦。
本项目是**以三易作为顶层调度范式，把任务分级、存档复盘、敏感门禁整合为一套闭环系统**。
